# AI Context: Standalone Local Workout Tracker App

## Project Overview
You are analyzing the technical specifications and UI/UX flows for a brand-new, standalone mobile workout tracking application built for Sebastian Herrera. 

## Architectural Constraints (CRITICAL)
- **No Backend / Serverless:** This is a 100% client-side application. No cloud databases, no user authentication APIs, and no remote backend sync for this phase.
- **Local Persistence:** All data (routines, exercise library, history, weights, and tracked series) MUST be stored locally on the device utilizing a local database (e.g., SQLite via Ionic/Capacitor or local Key-Value storage).
- **Offline-First:** Performance must be instantaneous and fully functional without an internet connection.

## Tech Stack & Language Guidelines
- **Core Stack:** Angular + Ionic (Mobile UI / Capacitor).
- **Project Language:** All code, component naming, schema definitions, and comments MUST be in English. 
- **User Interface Language:** UI texts, labels, and exercise names seen by the user are in Spanish (Latin America) as defined in the layouts.

## Design System Tokens
- **Background:** Slate 900 (`#0F172A`)
- **Cards/Surfaces:** Slate 800 (`#1E293B`)
- **Primary Accent / Success:** Emerald 500 (`#10B981`)
- **Main Text:** Slate 50 (`#F8FAFC`)
- **Muted Text / Inactive:** Slate 500 (`#64748B`)
- **Border Radius:** 12px to 16px (Smooth corners)

## Core UX Mechanics (The "Series Pips" Logic)
Instead of standard checkboxes or manual text inputs during standard workout execution:
1. Every exercise is rendered as a standalone Card inside a `BLOQUE` (Super-sets/Circuits).
2. Exercises feature interactive horizontal series buttons (Pips) that represent target reps and weights (e.g., a 10-8-6-4 pyramid).
3. Tapping a pip toggles its state from Pending to Completed (`#10B981` background).
4. When all pips inside a Card are completed, the entire card dims to 60% opacity and inherits a solid Emerald border.
5. Time-based exercises (e.g., 30" Planks) embed a native countdown timer directly into the pip row.
6. Modification of Weights: Tapping the card secondary action triggers a BottomSheet with a custom wheel selector (+2.5kg / -2.5kg) to update the current local session weight.

## Navigation Flow
`Home Dashboard` -> `Routine Selector` -> `Weekly Day Selector` -> `Active Workout Mode` -> `Progress Analytics Chart`.
